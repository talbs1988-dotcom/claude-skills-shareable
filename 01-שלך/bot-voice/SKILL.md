# הוספת קול לבוט הוואטסאפ

## מה זה עושה

מוסיף לבוט את היכולת להבין הודעות קוליות. התלמיד מקליט בוואטסאפ, הבוט מתמלל ועונה.

התמלול רץ **על המחשב של התלמיד**:
- אין מפתח API ואין צורך להירשם לשום שירות
- אין עלות — לא לפי דקה ולא לפי חודש
- ההקלטות לא יוצאות מהמחשב

## ⚠️ שלושה דברים לוודא לפני שמתחילים

1. **מקום בדיסק** — צריך לפחות 3 ג'יגה פנויים. המתקין בודק את זה לבד ועוצר אם אין.
2. **הרץ מתוך תיקיית הבוט** — לא מתיקיית הבית.
3. **אל תדווח למשתמש שזה עובד לפני שהבדיקה בשלב 5 עברה.** המתקין מתמלל הקלטה אמיתית ומדפיס את התמליל. אם הוא לא הדפיס תמליל — זה לא עובד.

## איך מתקינים

### שלב א — למצוא את תיקיית הבוט

חפש תיקייה שבה יש אחד מהקבצים `green-api-bot.js`, `bot.js` או `index.js`.
במקרים הרגילים זו אחת מאלה:

```
~/claude-whatsapp-bot
~/talbs-whatsapp-bot
~/whatsapp-bot
```

אם לא מצאת — שאל את המשתמש איפה הבוט שלו.

### שלב ב — להריץ את המתקין

```bash
node ~/.claude/skills/bot-voice/install.mjs <תיקיית-הבוט>
```

בווינדוס:

```powershell
node $HOME\.claude\skills\bot-voice\install.mjs <תיקיית-הבוט>
```

המתקין עושה חמישה שלבים ומדפיס כל אחד. השלב החמישי מתמלל הקלטה אמיתית בעברית
ומדפיס את התמליל. **זו הראיה שזה עובד.**

### שלב ג — לחבר לקוד של הבוט

המתקין מעתיק את `voice.js` לתיקיית הבוט אבל **לא נוגע בקוד של הבוט עצמו** —
כדי לא לשבור אותו. את החיבור עושים ידנית, והוא שלוש שורות.

מצא בקובץ הבוט את המקום שבו הודעה בלי טקסט נזרקת. הוא נראה בערך כך:

```js
const text = extractText(messageData).trim();
if (!text) {
  log(`📎 ${type} non-text (${messageData.typeMessage}) — ignored`);
  return;
}
```

הוסף **לפני** ה-`return` טיפול בהקלטה:

```js
const text = extractText(messageData).trim();
let voiceText = "";
if (!text && messageData.typeMessage === "audioMessage") {
  try {
    const { transcribeBuffer } = await import("./voice.js");
    const url = messageData.fileMessageData?.downloadUrl;
    if (!url) throw new Error("אין קישור להקלטה");
    const res = await fetch(url, { signal: AbortSignal.timeout(60000) });
    if (!res.ok) throw new Error(`הורדת ההקלטה נכשלה: ${res.status}`);
    voiceText = await transcribeBuffer(Buffer.from(await res.arrayBuffer()));
    log(`🎤 תומלל: ${voiceText.slice(0, 80)}`);
  } catch (e) {
    log(`❌ שגיאת קול: ${e.message}`);
  }
}
const finalText = text || voiceText;
if (!finalText) {
  log(`📎 ${type} non-text (${messageData.typeMessage}) — ignored`);
  return;
}
```

ואז החלף בהמשך הקוד את השימושים ב-`text` ב-`finalText`.

**חובה אחרי השינוי:**

```bash
node --check <קובץ-הבוט>
```

אם זה נכשל — שחזר את הגיבוי ואל תשאיר את הבוט שבור.

### שלב ד — להפעיל מחדש ולבדוק באמת

הפעל מחדש את הבוט, ואז **בקש מהמשתמש לשלוח הקלטה אמיתית בוואטסאפ**.
בדוק בלוג שמופיעה שורת `🎤 תומלל`.

הפעלה מחדש שהצליחה היא לא ראיה שהקול עובד. רק הקלטה שתומללה היא ראיה.

## אם משהו לא עובד

| מה שקרה | למה | מה עושים |
|---|---|---|
| `צריך לפחות 3 ג'יגה` | הדיסק מלא | לפנות מקום |
| ההתקנה נתקעת | אינטרנט איטי, המודל גדול | לחכות, להריץ שוב |
| `התמלול חזר ריק` | ההקלטה שקטה או קצרה מדי | לנסות הקלטה אחרת |
| `שגיאת קול: אין קישור להקלטה` | Green API לא החזיר קישור | לבדוק שהאינסטנס מחובר |
| התמלול לא מדויק | המודל קטן מדי | להגדיר מודל גדול יותר (ראה למטה) |

## המודל — ומה נבדק בפועל

ברירת המחדל היא `onnx-community/whisper-large-v3-turbo` בגרסה מכווצת (`q8`).
הבחירה הזאת נבדקה על עברית, והמספרים:

| מודל | תמליל | זמן תמלול |
|---|---|---|
| whisper-small | שגיאות שמשנות את המשמעות | 2.7 שניות |
| turbo, לא מכווץ | מדויק | 17.7 שניות |
| **turbo מכווץ (ברירת המחדל)** | **מדויק** | **4.2 שניות** |

המודל יורד פעם אחת ונשמר ב-`.voice-models` בתיקיית הסקיל — לא בתוך
`node_modules`, כדי שהתקנת חבילות מחדש לא תמחק אותו.

**הערה על הבדיקה:** היא נעשתה על קול מסונתז, שהוא מבחן קשה מהרגיל.
דיבור אנושי אמיתי יוצא בדרך כלל מדויק יותר, לא פחות.

### לשנות מודל

בקובץ `.env` של הבוט:

```
VOICE_MODEL=Xenova/whisper-small
VOICE_DTYPE=q8
```

מודל קטן = מהיר וקל, אבל פחות מדויק בעברית. לא מומלץ אלא אם המחשב חלש מאוד.
